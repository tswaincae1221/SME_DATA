# TA/HM 단계적 피처 엔지니어링 최적화

## 결론

기존 `CatBoost + residual LSTM`을 고정 기준으로 두고, 규정상 허용되는 신규 피처군을
하나씩 추가한 다음 그룹 단위와 상관 군집 단위로 다시 제거했다. 최종적으로 TA에는
23개 피처의 Ridge 잔차 보정 분기를 16% 결합하고, HM은 신규 분기를 사용하지 않는 구성이
선택됐다.

2025 회고 평가에서 다음과 같이 개선됐다.

| 구성 | TA RMSE | HM RMSE | 대회식 점수 |
|---|---:|---:|---:|
| 기존 기준, seed 42 | 1.743523 | 7.441432 | 2.487666 |
| 최종 피처 최적화, seed 42 | **1.696216** | 7.441432 | **2.440359** |
| 변화 | **-0.047307 (-2.71%)** | 0.000000 | **-0.047307 (-1.90%)** |

HM의 대회 가중치는 0.1이지만 개선되지 않은 분기를 억지로 섞지 않았다. 이번 점수 향상은
전부 TA에서 발생했다.

## 누수 방지와 규정 준수

- 피처 선택: 2023, 2024 rolling OOF residual 검증
- 잔차 학습용 기존 모델 예측: 2022~2024 rolling OOF
- 마지막 확인: 2025, 피처·Ridge alpha·가중치 선택에는 사용하지 않음
- 직접 연도항: 사용하지 않음
- 입력: LE1B 16채널, 공식 LAT/LON/ALT, 날짜·시각·좌표 계산값, 입력 결측 구조만 허용
- ASOS TA/HM: 학습·평가 라벨로만 사용
- 금지 자료: ASOS lag/평균, 기후값, 수치예보·재분석, 외부 DEM·토지피복·해안거리 등

새 Ridge는 TA를 처음부터 예측하지 않는다. 기존 모델의 OOF 오차
`actual_TA - baseline_TA`만 학습하고, 최종적으로 다음처럼 결합한다.

`TA_final = 0.84 × TA_baseline + 0.16 × TA_residual_corrected`

이 구조는 신규 시간피처 모델의 연도별 평균기온 편향이 최종 예측을 지배하지 못하게 한다.

## 피처군 전진 추가 결과

### TA

| 추가 후보 | 기존 40개 대비 OOF RMSE 변화 | 채택 |
|---|---:|---|
| 12~14시 채널·채널차이 평균 | **-0.105761** | 채택 |
| 최근 변화량 묶음 | -0.025156 | 단독 차선, 미채택 |
| 물리 상호작용 | -0.046237 | 단독 차선, 미채택 |
| 시간 변동성 | +0.081598 | 기각 |
| 전체 시간기울기 | +0.060641 | 기각 |
| profile/regime | +0.065706 | 기각 |
| 결측 구조 | 0.000000 | 기각 |

평균 피처를 채택한 뒤 다른 피처군을 추가하면 최소 개선 폭 0.005를 넘지 못했다. 따라서
시간 통계를 무더기로 넣지 않고, `12~14시 평균 level`만 남겼다.

### HM

시간기울기군이 전진 단계에서 OOF RMSE를 0.095809 낮췄지만, 이후 중복 그룹 제거에서는
기존 지점 좌표만으로 동일하거나 더 나은 결과가 나왔다. 최종 앙상블 최적 가중치는
`baseline=1.0, engineered=0.0`이었다. 따라서 HM 피처 추가는 채택하지 않았다.

## TA 그룹 단위 제거

전진 추가 직후 58개에서 다음 순서로 제거됐다.

1. 기존 날짜·태양 10개 제거: OOF RMSE -0.060518
2. 기존 14시 채널차이 11개 제거: OOF RMSE -0.046222
3. 기존 LAT/LON/ALT 제거: OOF RMSE -0.002162

잔차 보정 분기에는 기존 14시 raw 채널과 새 12~14시 평균 피처만 남았다. 좌표와 날짜 정보가
기존 CatBoost+LSTM에서 이미 반영됐기 때문에, 잔차 Ridge에서는 추가 정보보다 중복정보로
작용한 것으로 해석한다.

## 상관 중복 제거

학습기간에서 `|r| >= 0.985`인 피처군만 검사하고, 제거 후 OOF RMSE 저하가 단계당
0.003 이내일 때만 삭제했다. 34개에서 11개가 제거돼 23개가 남았다.

제거된 피처는 다음과 같다.

- `VI005_last`
- `IR087_last`, `IR105_last`, `IR112_last`, `IR123_last`, `IR133_last`
- `IR087_mean_z`, `IR096_mean_z`, `IR105_mean_z`, `IR112_mean_z`, `IR133_mean_z`

적외 채널의 절대값과 2시간 평균이 강하게 묶였고, 그중 단독 제거 영향이 작은 값을 순서대로
삭제했다. 11개 제거 전 OOF RMSE는 3.005830, 제거 후 3.007518로 차이는 0.001688이었다.

## 3시드 재검증

피처 선택을 반복하지 않고 위 23개를 고정한 뒤, 기존 LSTM seed 42~44 각각에 잔차 Ridge만
재학습했다.

| seed | TA RMSE | HM RMSE | 대회식 점수 | TA 신규분기 가중치 |
|---:|---:|---:|---:|---:|
| 42 | 1.696216 | 7.441432 | 2.440359 | 0.16 |
| 43 | **1.685159** | 7.262872 | **2.411446** | 0.18 |
| 44 | 1.711569 | **7.208921** | 2.432461 | 0.16 |
| 평균 | **1.697648** | **7.304409** | **2.428089** | - |
| 표준편차 | 0.013263 | 0.121694 | 0.014944 | - |

기존 3시드 평균은 TA 1.749592, HM 7.304409, 점수 2.480033이었다. 최종 구성은 TA 평균을
0.051944°C(2.97%), 점수를 0.051944(2.09%) 개선했다. 세 시드에서 모두 TA 개선이
재현됐으므로 단일 초기화 우연으로 보기는 어렵다.

## 공간 피처 다음 단계

로컬에는 전체 2019~2025 NC가 없어 공간 피처 수치 실험은 이번 결과에 포함하지 않았다.
대신 `extract_shortterm_spatial_features.py`를 추가했다.

- 기본 채널: thermal/WV 10개
- 시각: 14:00 KST
- 패치: 5 km, 15 km
- 통계: 평균, 표준편차, p10, p90, 유효비율, 중심-주변 평균
- 누락 NC: NaN과 issue CSV로 기록
- 재실행: 완료된 날짜 checkpoint 자동 재사용

공간 CSV가 생성되면 optimizer에 `--spatial-features-csv`를 넘겨 `new_spatial_patch`를 다른
피처군과 동일하게 전진 추가·후진 제거·상관 제거한다. 2025 결과를 보고 공간 피처를
수동 선택하지 않는다.
