# TA 실험 1~3 결과 보고서

## 검증 설계

- OOF 검증: 2022, 2023, 2024를 각각 한 번씩 미래 연도로 보류
- 최종 평가: 2025년 672개 관측소·날짜 표본
- 교정 상수와 모든 앙상블 가중치는 2022~2024 OOF 2,007건만으로 결정
- 2025 라벨은 최종 성능 계산 전까지 사용하지 않음
- 입력은 LE1B 16채널, 공식 station 위도·경도·고도, 날짜·태양 계산값으로 제한

## 실험 정의

1. `Exp1_FullCalibrated`: 직접 TA LSTM + CatBoost/Ridge 계층 앙상블을 모델별 OOF 평균 편향으로 보정
2. `Exp2_CatResidualLSTM`: LSTM이 절대기온 대신 `TA - CatBoost 예측` 잔차를 학습하고 CatBoost 예측에 더함
3. `Exp3_NoRidge`: 보정된 직접 TA LSTM과 CatBoost만 사용하여 Ridge 제거 효과 측정

## 2025 결과

| 모델 | RMSE | MAE | Bias | Corr |
|---|---:|---:|---:|---:|
| CatBoost raw | 2.6044 | 2.1641 | -1.9885 | 0.7281 |
| CatBoost calibrated | 2.1827 | 1.7181 | -1.3913 | 0.7281 |
| 기존 계층 앙상블 raw | 2.8902 | 2.4820 | -2.3426 | 0.7089 |
| 실험 1: 계층 앙상블 보정 | 2.4668 | 2.0518 | -1.8053 | 0.7137 |
| **실험 2: CatBoost + residual LSTM** | **1.9371** | **1.5075** | **-1.0389** | **0.7412** |
| 실험 3: Ridge 제거 | 2.4651 | 2.0502 | -1.8037 | 0.7140 |

실험 2는 CatBoost raw 대비 RMSE 25.6%, 보정 CatBoost 대비 11.3%, 실험 1 대비 21.5% 개선했다. paired bootstrap에서 실험 2와 보정 CatBoost의 RMSE 차이는 -0.2456이며 95% 구간은 -0.3117~-0.1805이다.

## OOF 선택값

| 항목 | 값 |
|---|---:|
| CatBoost offset | +0.5973℃ |
| Ridge offset | +0.1181℃ |
| 직접 LSTM offset | +0.5253℃ |
| 보정 계층 내 CatBoost 비중 | 0.96 |
| 보정 계층 내 직접 LSTM 비중 | 0.90 |
| Ridge 제거 모델의 직접 LSTM 비중 | 0.90 |
| residual LSTM scale | 1.52 |
| residual 최종 offset | +0.6029℃ |

Ridge의 실질 최종 비중은 `(1 - 0.90) × (1 - 0.96) = 0.004`, 약 0.4%였다. Ridge 제거 전후 RMSE 차이도 0.0017에 불과하므로 현재 구성에서는 제거하는 편이 단순성과 재현성 면에서 낫다.

## 해석 및 다음 개선점

잔차 LSTM은 CatBoost가 설명하지 못한 12~14시 변화 정보를 직접 학습하여, 절대 TA를 별도로 예측한 뒤 평균내는 방식보다 안정적이었다. 다만 OOF 편향은 2022년 +2.38℃, 2023년 -0.78℃, 2024년 -1.58℃로 연도 방향성이 남았고 2025에서도 -1.04℃ 저온 편향이 남았다. 다음 실험에서는 pooled 상수 하나보다 최근 연도에 높은 가중치를 주는 calibration 또는 OOF 선형 추세 교정을 비교해야 한다.

결측 여부는 날짜와 완전히 독립적이지 않으므로 현재 결과만으로 결측이 성능 하락의 원인이라고 단정할 수 없다. 학습 시 임의 timestep/channel masking을 적용한 뒤 동일 날짜 내 synthetic missing 비교가 필요하다.

현재 추천 구조는 `CatBoost + 1.52 × residual LSTM + OOF calibration`이며 Ridge는 제외한다.
